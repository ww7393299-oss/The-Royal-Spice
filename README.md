## 🍽️ About The Project

**The Royal Spice** is a modern, elegant, and fully responsive single-page restaurant website designed for fine dining establishments. Built entirely with **HTML5**, **CSS3**, and **vanilla JavaScript** — no frameworks, no dependencies (except Google Fonts & Font Awesome CDN).

Whether you run an Indian restaurant, a continental bistro, or a multi-cuisine fine dining place, this template is fully customizable to match your brand.

### 🌟 Key Highlights
- ⚡ **Zero dependencies** — Pure HTML/CSS/JS
- 📱 **Fully responsive** — Looks perfect on mobile, tablet, and desktop
- 🎨 **Elegant dark & gold theme** — Luxury fine dining aesthetic
- 🍛 **Interactive menu** with category filtering (Starters, Main Course, Desserts, Beverages)
- 📅 **Table reservation form** with date, time, guests, and occasion selection
- ✨ **Smooth scroll animations** and hover effects
- 🖼️ **Masonry photo gallery** with hover overlays
- ⭐ **Customer testimonials** section

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Hero Section** | Full-screen banner with parallax background, animated text, and dual CTA buttons |

| **Contact Info** | Elegant contact cards with address, phone, email, and opening hours |

| **Scroll Animations** | Elements fade in smoothly as you scroll down the page |

## 🎨 Customization Guide

### 1. Change Restaurant Name
Search and replace all instances of **"The Royal Spice"** with your restaurant name.

### 2. Update Contact Details
Find these sections and update:
- Phone number: `+91 12345 67890`
- Email: `info@theroyalspice.com`
- Address: `123 Culinary Street, Food District`
- Opening hours

### 3. Replace Images
All images are loaded from Unsplash via URL. Replace them with your own:
```html
<img src="YOUR_IMAGE_URL" alt="Description">
```

### 4. Update Menu Items
Find the `<div class="menu-grid">` section and edit dish names, descriptions, prices, and categories.

### 5. Change Brand Colors
Edit the CSS variables at the top of the `<style>` tag:
```css
:root {
  --gold: #d4a853;        /* Primary accent color */
  --dark: #1a1a1a;        /* Dark background */
  --cream: #faf7f2;       /* Light background */
}
```

### 6. Add Your Social Links
Update the social media links in the footer:
```html
<a href="YOUR_FACEBOOK_URL"><i class="fab fa-facebook-f"></i></a>
<a href="YOUR_INSTAGRAM_URL"><i class="fab fa-instagram"></i></a>
```

## 🚀 Deployment

### GitHub Pages (Recommended — Free)

1. Go to your repository **Settings** → **Pages**
2. Under **Source**, select **Deploy from a branch**
3. Select the `main` branch and `/ (root)` folder
4. Click **Save**
5. Your site will be live at `https://YOUR_USERNAME.github.io/the-royal-spice/`

### Netlify (Drag & Drop)

1. Go to [netlify.com](https://netlify.com)
2. Drag and drop your project folder
3. Your site is live instantly!

### Vercel

1. Install Vercel CLI: `npm i -g vercel`
2. Run: `vercel`
3. Follow the prompts
